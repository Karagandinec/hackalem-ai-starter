## Коротко о проекте

Каркас под хакатон HackAlem AI (23 сентября 2026, Астана, МВЦ «EXPO», старт 14:00),
трек **«Добывающая промышленность»**. Предметка: парк техники на разрезе (`Asset`),
события с ней (`Event`), сотрудники (`User`). Конкретный кейс внутри трека объявляют
на площадке, поэтому модели широкие и легко переименовываются.

Сроки: 23.09 офлайн-этап, 24–28.09 проверка решений жюри офлайн, 29.09 Demo Day,
01.10 награждение.

Монорепо: `backend/` (FastAPI + SQLAlchemy + SQLite) и `frontend/` (Vite + React + TypeScript).

## Команды

```
make check    # ЕДИНСТВЕННАЯ команда проверки: pytest + tsc --noEmit
make dev      # backend :8000 + frontend :5173
make seed     # пересоздать базу и залить 140 единиц техники с событиями
```

На Windows `make` обычно не установлен — есть шим `.\make.cmd` с теми же командами.

⛔ `npm run dev` и `uvicorn` **не запускать как проверку** — это вечные процессы,
они вешают сессию до таймаута. Подробности и правильный способ поднять сервер — в AGENTS.md.

## Особенности окружения

- Python-зависимости в `backend/.venv`, вызывать как `backend/.venv/Scripts/python.exe` (Windows).
- Файлы `*.cmd` обязаны быть с CRLF — cmd.exe с LF молча зависает. Следит `.gitattributes`.
- В консоли Windows кириллица от Python едет без `PYTHONUTF8=1`; в make-целях он уже выставлен.
- Ключи только из `.env` (в `.gitignore`). Без `OPENAI_API_KEY` проект работает на заглушке —
  это штатный режим, а не поломка.
